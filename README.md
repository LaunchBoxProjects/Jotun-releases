# Jotun

A calm space to bring images, articles, PDFs, and video references together around your projects. Your library stays on your computer.

## Download the alpha

- **[macOS — Apple silicon](https://github.com/LaunchBoxProjects/Jotun-releases/releases/download/v0.1.2/Jotun-0.1.2-arm64.dmg)**: M1 or later, macOS 13 or later. Developer ID signed and notarized by Apple. Open the DMG, drag Jotun into Applications, and launch it from there. Intel Macs are not supported; compatibility on the minimum macOS version is not yet physically verified.
- **[Windows — Intel/AMD 64-bit](https://github.com/LaunchBoxProjects/Jotun-releases/releases/download/v0.1.2/Jotun-0.1.2-windows-x64-setup.exe)**: unsigned alpha installer. Run setup and launch Jotun from the Start menu. A native Windows ARM installer is not provided.

### Windows security warning

This Windows alpha is not code-signed yet. You may see **“Windows protected your PC”**. If you downloaded the installer from this official repository, choose **More info → Run anyway**, if available. Some security policies may block installation. Do not disable your antivirus or Windows security protections. Windows signing is being investigated.

[Read the release notes](https://github.com/LaunchBoxProjects/Jotun-releases/releases/tag/v0.1.2) for platform details and known limitations. GitHub's automatic source-code archives contain this repository's documentation, not the app installer or private application source.

## Updates

Updates are manual during the alpha. Quit Jotun and download the new installer. On macOS, replace the app in Applications; on Windows, run the new installer. Jotun stores its library separately from the application. Keep your original reference files; this alpha should not be your only copy of important material.
