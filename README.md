# Jotun

A calm, local-first visual reference library for macOS. Keep images, web articles, PDFs, and video together in collections, with search, favourites, and focused previews.

## Download the alpha

**[Download Jotun 0.1.2 for Apple silicon](https://github.com/LaunchBoxProjects/Jotun-releases/releases/download/v0.1.2/Jotun-0.1.2-arm64.dmg)**

[Release notes](https://github.com/LaunchBoxProjects/Jotun-releases/releases/tag/v0.1.2). The app and installer are Developer ID signed and notarized by Apple.

Open this repository's **Releases** section and download the `.dmg` attached to the alpha release. The first build is for Apple-silicon Macs (M1 or later); it does not support Intel Macs.

The current 0.1.2 app bundle declares macOS 13 or later as its minimum version. Compatibility on that minimum version has not yet been physically verified.

Open the disk image, drag **Jotun** into **Applications**, then launch it from Applications. GitHub also offers source-code archives automatically; those are not the app installer.

Jotun is early software. Keep your original reference files and avoid using the alpha as your only copy of important material.

## Updates

Updates are manual during the alpha. Quit Jotun, download the new installer, and replace the app in Applications. Jotun stores its library separately from the application. Report any library problems before continuing to use the affected library.

## Feedback

Open an issue in this repository. Include the Jotun version, macOS version, Mac model, what you expected, and what happened. Screenshots help; remove private content before sharing them.
